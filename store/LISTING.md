# Chrome Web Store listing: copy and paste

## Name
Document Zoom for Google Drive

## Summary (max 132 characters)
Zoom Google Docs, Sheets, Slides and Drive previews with Ctrl+Alt+scroll, without zooming the toolbars or the whole page.

## Category
Workflow & Planning (or: Tools)

## Description
Ctrl + scroll wheel in Chrome zooms the whole page, toolbars and menus
included. This extension lets you zoom just the document instead.

Hold Ctrl + Alt and scroll to zoom in and out of:
• Google Docs
• Google Sheets
• Google Slides
• PDFs and other file previews in Google Drive

The extension uses each app's own zoom control, the same one you would use
from the toolbar. Text stays sharp, and clicking, selecting and editing keep
working as normal. Plain scrolling is unchanged.

Options:
• Choose the keys to hold: Ctrl + Alt (default), Alt, Ctrl + Shift or Alt + Shift
• Set how much each wheel notch zooms (default 10%)
• Invert the scroll direction

Privacy: the extension collects no data and makes no network requests. It
only stores your settings.

Tip: some Linux desktops use Ctrl + Alt + scroll for their own shortcuts. If
nothing happens, choose a different key combination in Options.

This extension is not made by or affiliated with Google.

## Privacy practices tab

### Single purpose
Lets the user zoom documents in Google Docs, Sheets, Slides and Drive
previews with a modifier + mouse wheel, without zooming the whole browser page.

### Permission justification: storage
Saves the user's settings: which modifier keys to use, the zoom step and the
scroll direction.

### Host permission justification (docs.google.com, drive.google.com)
The extension has to run on these pages to catch the modifier + wheel
shortcut and press the page's own zoom controls. It does not read or send
document contents.

### Remote code
No, I am not using remote code.

### Data usage
Tick nothing: the extension collects no user data. Then certify the three
statements (no selling, no unrelated use, no creditworthiness use).

### Privacy policy URL
https://github.com/bjartesorensen/googledrivezoom/blob/main/PRIVACY.md
